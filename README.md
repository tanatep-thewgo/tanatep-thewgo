I spend most of my time somewhere between a Python notebook and a Unity scene — training a model, wiring up a sensor, or figuring out why a hand-tracking demo won't run on someone else's laptop. My senior project, **GestureTalk**, taught a computer to read Thai Sign Language in real time. A breadboard full of jumper wires taught me that "smart home" mostly just means a lot of small things that need to talk to each other reliably. A VR shooting range taught me that balancing enemy waves is harder than it looks.

**What I've been doing lately:**
- Porting GestureTalk from a Python desktop app into a browser-based PWA — same MediaPipe hand-tracking, but the whole inference step now runs client-side in JavaScript, no server involved.
- Picking up React and Node.js by rebuilding a few old projects with them.
- Reading more about how CNNs and detection models actually work under the hood, instead of just calling `.fit()`.
